# Task Manager API

A simple RESTful Task Manager API built using Node.js and Express.js.

This project implements CRUD operations for managing tasks using an in-memory data structure.

## Features

- Get all tasks
- Get a task by ID
- Create a new task
- Update an existing task
- Delete a task
- API testing using Postman



For Setup:
 - Clone a repository
 - Run 'npm i express'
 - Run 'node app.js'
